# Cat Break

A small, funny cat meme gallery. The site and all 19 cat photos are included in this repository, so the gallery works without external image hosts or a database.

## Run it on another computer

1. Install Node.js 18 or newer.
2. Clone this repository:

   ```sh
   git clone https://github.com/meowshmalloww/AttackTheCatWebsite.git
   cd AttackTheCatWebsite
   ```

3. Start the site:

   ```sh
   npm start
   ```

4. Open <http://127.0.0.1:3000> in a browser.

No `npm install` is needed. The server uses only Node.js built-in modules. On Windows, you can also double-click `start.bat`.

The server listens on this computer only (`127.0.0.1`). Set the `PORT` environment variable to use another local port.
